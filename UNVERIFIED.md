# Unverified against DOOM (2016): audit list

Rule (COORDINATION.md rule 6): every value and behaviour comes from DOOM's own data (decls, cvars, md6, maps,
default.cfg) or static analysis of DOOMx64.exe, cited in a code comment. Anything else is a stand-in, marked
`INTERIM` in the code, and must be replaced (or proven) before other work relies on it. Address-level notes live
in the git-ignored `gamedata/re/` (index: `gamedata/re/SPEC.md`).
